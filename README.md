## Mis proyectos

- **[SIGIA — Gestión Inteligente de Incidencias](https://github.com/fvtre/SIGIA)**  
  Demo para gestionar incidencias, con dashboard, vistas de tabla y Kanban, asignaciones, seguimiento SLA e informes.

- **[Brasa](https://github.com/fvtre/brasa)**  
  Marketplace digital para descubrir y organizar eventos y conectar clientes con prestadores de servicios.

- **[ReparoTuFuga](https://github.com/fvtre/ReparoTuFuga)**

- **[Project Bikes](https://github.com/fvtre/Project_Bikes)**  
  Aplicación de tienda y administración de bicicletas, productos, ventas, arriendos y servicios técnicos.

- **[Carpooling App](https://github.com/fvtre/carpooling-app)**  
  Aplicación relacionada con viajes compartidos.

- **[Librería Java](https://github.com/fvtre/Libreria_Java)**

- **[Project News](https://github.com/fvtre/Project_News)**

- **[IECA](https://github.com/fvtre/IECA)**

- **[Somak](https://github.com/fvtre/Somak)**
